# Off by a beat: the effects of temporal misalignment in reinforcement learning for sepsis treatment (npj Digital Medicine, 2026)

This repository contains the source code for replicating all experiments in the npj Digital Medicine 2026 paper, https://www.nature.com/articles/s41746-026-02625-2.

Repository content:

- `synthetic/` contains code for the experiments on the toy problem simulations.
- `mimic_sepsis/` contains code for the experiments on the MIMIC-III sepsis dataset.
